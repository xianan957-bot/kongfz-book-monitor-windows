# 孔夫子旧书网 Windows 商品监控提醒工具

这是与 Android 工程独立维护的 Windows 桌面版源码。它只在当前 Windows 用户的电脑本地保存配置、已处理商品和 WebView2 登录资料；不使用服务器、云数据库或买家侧官方 API。

## 当前范围

- 手动在内置 WebView2 中登录孔夫子旧书网，复用本机登录资料
- 固定五个独立监控任务：每个任务分别设置关键词、作者、出版社、最低/最高商品价格和 1～15 秒刷新间隔
- 五个任务各自拥有官网结果页、筛选、最低标价选择、本地去重、轮次和暂停状态；仅共用本机 WebView2 登录 Cookie
- 首次进入官网高级搜索结果页后，未发现符合条件的新品时按间隔刷新同一结果页；配置变更、登录失效或页面不再是对应结果页时才重新进入搜索。刷新仍会向官网请求最新结果，不能绕过网站的人机验证或访问频率限制
- 使用官网高级搜索对应的结果参数先按关键词、作者、出版社和商品价格区间缩小范围，再按“最新上架”只读取第一页已渲染商品；不会扫描全部分页
- 每个任务分别本地去重；不符合筛选条件的商品也会记录为该任务已处理，不会影响其他任务
- Windows 托盘通知；每个任务每轮只提示最终选中的最低商品价，通知点击仍打开该任务对应的商品页；停止任务时会清理该任务未显示的排队提示
- 主界面分别显示五个任务本次启动以来已完成的监控轮次；每次搜索尝试完成后计为一轮
- 每个任务有新的符合条件商品时，从自己当前第一页全部符合条件的商品中按商品标价选择最低价；直接在该任务内置的官网结果页定位商品卡片并点击网页自身的“立即购买”
- 孔夫子网站实际打开某任务的官方确认页后，只暂停该任务；没有匹配商品或无法打开确认页时，该任务继续下一轮
- 某个任务检测到孔夫子人机验证时，播放一次系统提示音、保留该任务验证页面并暂停该任务搜索请求；用户手动完成验证后，只对该任务恢复当前结果页的一次官网“立即购买”重试，随后继续该任务普通新品监控。不会拖动验证码、提交验证码、提交订单或绕过验证

## 明确不包含

- 自动提交订单或自动付款
- 自动填写账号密码、绕过验证码、绕过风控或绕过访问频率限制
- 服务器监控、云数据库、多账号、多电脑同步、管理后台或收费功能

孔夫子搜索页可能要求验证或提示搜索次数达到上限。验证码由用户手动完成；访问上限由网站控制，软件不会试图绕过它，并仅按用户设置的间隔继续尝试。

## 本地数据位置

运行后数据保存在：

`%LOCALAPPDATA%\KongfzBookMonitor`

其中 WebView2 Profile 包含登录 Cookie，应视为敏感本地数据，不要复制给其他人。

`monitor-rules.json` 保存五个任务的配置；`processed-items\<任务 ID>.json` 保存各任务独立的已处理商品记录。首次升级会把旧版单任务配置和已处理记录迁移到任务 1，旧文件不会被删除。

## 构建

要求：Windows 10 1809（17763）或更高版本、.NET 5 SDK、Microsoft Edge WebView2 Runtime。

```powershell
dotnet build .\KongfzBookMonitor.Windows\KongfzBookMonitor.Windows.csproj
```

本次提交不包含订单确认或支付自动化。
