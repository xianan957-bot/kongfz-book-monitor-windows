# 孔夫子旧书网 Windows 商品监控提醒工具

这是与 Android 工程独立维护的 Windows 桌面版源码。它只在当前 Windows 用户的电脑本地保存配置、已处理商品和 WebView2 登录资料；不使用服务器、云数据库或买家侧官方 API。

## 当前范围

- 手动在内置 WebView2 中登录孔夫子旧书网，复用本机登录资料
- 设置关键词、作者、出版社、最低/最高商品价格（不含运费）和 1～15 秒刷新间隔
- 首次进入官网高级搜索结果页后，未发现符合条件的新品时按间隔刷新同一结果页；配置变更、登录失效或页面不再是对应结果页时才重新进入搜索。刷新仍会向官网请求最新结果，不能绕过网站的人机验证或访问频率限制
- 使用官网高级搜索对应的结果参数先按关键词、作者、出版社和商品价格区间缩小范围，再按“最新上架”只读取第一页已渲染商品；不会扫描全部分页
- 本地去重；不符合筛选条件的商品也会记录为已处理
- Windows 托盘通知；每轮只提示最终选中的最低商品价，避免同页多个候选在 Windows 中排队弹出；点击最近一条通知可打开对应商品页
- 主界面显示本次启动以来已完成的监控轮次；每次搜索尝试完成后计为一轮
- 每轮有新的符合条件商品时，从当前第一页全部符合条件的商品中按商品标价（不含运费）选择最低价；直接在软件内置的官网结果页定位该商品卡片并点击网页自身的“立即购买”。不会为自动购买另开商品搜索页
- 孔夫子网站实际打开官方确认页后，监控自动暂停；没有匹配商品或无法打开确认页时继续下一轮
- 检测到孔夫子人机验证时，播放一次系统提示音、保留验证页面并暂停搜索请求；用户手动完成验证后，对恢复的当前结果页仅重试一次官网“立即购买”，随后继续普通新品监控。不会拖动验证码、提交验证码、提交订单或绕过验证

## 明确不包含

- 自动提交订单或自动付款
- 自动填写账号密码、绕过验证码、绕过风控或绕过访问频率限制
- 服务器监控、云数据库、多账号、多电脑同步、管理后台或收费功能

孔夫子搜索页可能要求验证或提示搜索次数达到上限。验证码由用户手动完成；访问上限由网站控制，软件不会试图绕过它，并仅按用户设置的间隔继续尝试。

## 本地数据位置

运行后数据保存在：

`%LOCALAPPDATA%\KongfzBookMonitor`

其中 WebView2 Profile 包含登录 Cookie，应视为敏感本地数据，不要复制给其他人。

## 构建

要求：Windows 10 1809（17763）或更高版本、.NET 5 SDK、Microsoft Edge WebView2 Runtime。

```powershell
dotnet build .\KongfzBookMonitor.Windows\KongfzBookMonitor.Windows.csproj
```

本次提交不包含订单确认或支付自动化。
